# Barber Shop Maracay 💈🇻🇪

Sitio web y aplicación web para barbería en Maracay, Estado Aragua, Venezuela.

## 🚀 Estructura del Proyecto
- **Frontend**: React 18 + Vite
- **Iconografía**: Lucide React
- **Estilos**: Sistema CSS responsivo oscuro y elegante (estilo barbería premium)
- **Ubicación de archivos**: `D:\Projects\barbershop-maracay`
- **Cache de npm**: Configurado en `D:\.npm-cache` para optimizar espacio del disco C.

## 📁 Carpetas
- `src/components/`: Componentes modulares (Hero, Servicios, Reservas, Barbero, etc.)
- `src/data/`: Datos de servicios, precios en USD y tasa Bs., barberos y horarios
- `src/hooks/`: Hooks personalizados
- `src/utils/`: Utilidades (formateo de moneda, generador de enlaces de WhatsApp)
- `src/assets/`: Imágenes y recursos estáticos
- `public/`: Archivos públicos estáticos

## 🛠️ Comandos
```bash
npm run dev     # Iniciar servidor de desarrollo local
npm run build   # Compilar para producción
npm run preview # Previsualizar build de producción
```
